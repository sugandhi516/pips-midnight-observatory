# Pip’s Midnight Observatory

A cozy, early-web portfolio for Pip, the gentle skull baby and Junior Dream Engineer at the Midnight Nursery. Built for haX.baby’s Baby’s First Website challenge.

## Run it

- Install Node.js 20 or newer.
- Run `pnpm install` (or `npm install`).
- Run `pnpm dev` to start the local development server.
- Run `pnpm build` to create the production site in `dist/`.
- Run `pnpm preview` to preview the production build locally.
- Deploy the `dist/` folder to Netlify, Vercel, Cloudflare Pages, or GitHub Pages. This project includes a GitHub Actions workflow that builds and deploys to Pages. Enable Pages in the repository settings and choose **GitHub Actions** as the build source.

## What’s inside

- Pip’s introduction, three project cards, and a three-scene scroll-reactive origin story.
- Pointer-reactive artwork, day/night palette, default-muted Web Audio chime, local visitor odometer, and a keyboard-accessible DREAM Easter egg (the small footer star also opens it).
- Responsive layouts, semantic landmarks, descriptive image alternatives, accessible control labels, and reduced-motion support.

## Character canon

Pip is a sleepy, gentle skull baby with warm eye pinpoints, a tiny crooked smile, a star nightcap, and a pink bow. Pip is curious and clumsy, giggles easily, and works as Junior Dream Engineer at the Midnight Nursery. The tone stays kind and cozy.

## Three alternate Pip directions

1. **Pip’s Rooftop Post Office** — a route-planning portfolio with tiny dream parcels and neighborhood delivery notes.
2. **The Lullaby Repair Shop** — an interactive sound workshop where Pip tunes music boxes for restless clouds.
3. **Pip’s Pocket Planetarium** — a star atlas that pairs each constellation with a bedtime story and nightlight.

## Three original Track 2 concepts

1. **Mallow** — a cloud-gardener who grows weather for houseplants; tagline: “A little rain, right on time.”
2. **Tink** — a baby robot who mends forgotten toys with warm, mismatched buttons; tagline: “Nothing lovely is beyond fixing.”
3. **Juniper** — a tiny moss dragon who keeps a lantern library under a garden bench; tagline: “Borrow a light, leave a story.”

## 48-hour roadmap

The official sprint runs 17–19 October 2026, with kickoff and code freeze at 17:17 IST (UTC+05:30). The official rubric weights functionality and polish at 35%, early-web soul at 30%, creativity and surprises at 20%, and clean craft at 15%.

- **Hours 0–6:** confirm the brief, sketch the visual system, establish the app shell, and ship the first working page.
- **Hours 6–18:** build the character intro, three showcases, story scenes, and mobile layout.
- **Hours 18–30:** add the theme, audio toggle, visitor counter, and secret; test touch and keyboard flows.
- **Hours 30–40:** check small screens, reduced motion, image loading, and production build; deploy a live draft.
- **Hours 40–48:** polish copy and spacing, verify links and credits, make the final deploy, and submit the live URL and public repository.
